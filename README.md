# neowiki-chart

A Helm chart that deploys the [NeoWiki](https://github.com/ProfessionalWiki/NeoWiki) stack
(MediaWiki + Neo4j + a SPARQL backend) to Kubernetes.

See **[neowiki/README.md](./neowiki/README.md)** for installation instructions, configuration
reference, and prerequisites.
